LFM3 Text / VL テキスト能力比較

このPCで同一のテキスト課題を実行。Text/VL × QAD 4bit/Q8_0 の4構成。画像入力なし。Qwenは保存済みの同一問題・採点条件の結果。

HumanEvalは選択20問、BFCLは選択80問の各1試行。公式フルスコアではありません。Text/VLは追加学習も異なるため、差を視覚機能の追加だけに帰属できません。

今回の6条件では、Text専用版が高得点だった条件は6、VL版が高得点だった条件は0でした。TextはLFM3-1.7B、VLはLFM3-VL-2Bです。これはコード生成・関数呼び出しの選択課題での結果で、日本語一般能力や文章読解全般の順位ではありません。

条件と読み方

  • HumanEval: 前回と同じ20問・制限付き採点器。temperature 0.6、seed 42、4096出力トークン。思考ON/OFFの実行順は問ごとに交互。
  • BFCL: 前回と同じ4カテゴリ各20問、temperature 0、1024出力トークン、思考OFF指定。ツールは実行せず、公式ASTチェッカーで呼出内容を採点。
  • 共通: context 65536、1 slot、同じb11960 CUDA 12.4。VLはF16画像処理モデルも読み込むが入力はテキストのみ。
  • Qwenの旧結果はb11946。runtime・量子化・CPU/GPU配置が異なるため、速度差をモデルだけの差とは扱わない。
  • OFF指定でも説明文中で検討を続ける場合がある。reasoning_contentの有無は別記録。ONの思考も4096トークンに含む。未完了の思考からコードを救済しない。
  • 採点器の許可構文・import制限により実行拒否になる場合がある。モデルの誤りと区別して失敗分類を保持。
  • メモリは周期観測のシステム値で、厳密なピークではない。
